## Open work

Open work lives in GitHub issues on `maxhawksby/go2-fusion`. Use the `gh` CLI. The five triage labels are defined in `docs/agents/triage-labels.md`.

Decisions are short records in `docs/adr/`. Read the ones that touch your area. If your change goes against one, say so in the pull request instead of quietly overriding it.
