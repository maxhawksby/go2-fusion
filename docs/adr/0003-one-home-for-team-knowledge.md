# One home for team knowledge

Date: 2026-10-22

## Context

The old guides (test log, lab checklist, fusion record, WSL, Windows and Mac guides, command cheat sheets) repeated and contradicted each other.

## Decision

Explanations live only in `README.md` and `docs/wiki/`. The old guides were folded into wiki pages and deleted. READMEs next to code keep only how to build, run and test.

## Consequences

One place to look and one place to fix. Since 2026-11-11, open work lives only in GitHub issues and new decisions in `docs/adr/`.
